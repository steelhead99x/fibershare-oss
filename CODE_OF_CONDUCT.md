# Code of Conduct

This project is maintained by BitPrairie LLC.

## Expected behavior

- Be respectful and specific.
- Keep this repository public-safe. Do not post secrets, private herd data, payment setup, or personal data.
- Critique the work, not the person.

## Unacceptable behavior

- Harassment, insults, or threats
- Publishing someone else's private information
- Adding secrets, prices, or real collar data to the repo or the issues

## How to report

If you can say it in public, open a GitHub issue on [fibershare-oss](https://github.com/steelhead99x/fibershare-oss/issues).

If it should stay private, email [legal@bitprairie.com](mailto:legal@bitprairie.com).

We will look at reports and may hide comments, lock threads, or block further participation.
